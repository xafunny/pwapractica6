# Fuerza Pro

Sistema de gestión de un gimnasio. Proyecto final de Programación Web Avanzada (Ejercicio 10).

**Integrantes:** Jhoao Guala, Keyla Duran
**Sitio:** https://fuerzapro.infinityfreeapp.com

## Tecnologías

HTML, CSS, Bootstrap 5, JavaScript, PHP 8 (sin frameworks) y MySQL.

## Instalación

1. Copiar el proyecto en `htdocs` (XAMPP) o `www` (Laragon).
2. En phpMyAdmin crear la base de datos `gimnasio` e importar `gimnasio.sql`.
3. Abrir `http://localhost/pwapractica6/`.
